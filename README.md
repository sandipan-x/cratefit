# CrateFit

Free dog crate size calculator: measure your dog, get the right standard crate size, divider tips and size chart. No signup.

## Features
- Two-measurement sizer mapped to standard commercial crate sizes via the 4-inch rule
- Breed quick-pick presets for 12 popular breeds
- Puppy divider planner plus a full standard size chart with interior dimensions
